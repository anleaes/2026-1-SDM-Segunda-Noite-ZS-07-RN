INSTRUÇÃO PARA COPILOT
---------------------
Ao gerar código, sugestões ou refatorações para este repositório, aplique e mantenha os princípios SOLID. Sempre analise o projeto inteiro antes de propor mudanças: leia os arquivos relevantes, identifique responsabilidades, dependências e pontos de acoplamento. Para cada mudança proposta, explique brevemente como ela preserva ou melhora:

- Single Responsibility: cada módulo/classe tem uma única razão para mudar.
- Open/Closed: extensível sem modificar o comportamento existente.
- Liskov Substitution: subclasses mantêm contratos das superclasses.
- Interface Segregation: interfaces específicas em vez de gerais.
- Dependency Inversion: dependa de abstrações, não de implementações.

Cite os arquivos e trechos relevantes que embasam suas sugestões.
Não comenta nada no código.
